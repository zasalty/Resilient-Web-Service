# Resilient-Web-Service
# Resilient Web Service with Automated Backup and DDoS Failover/Load Balancing

## Project Overview

The goal of this project is to create a simple web service that can remain available during server failures or high traffic. We will explore load balancing, automatic failover, DDoS protection, and automated backups to improve the reliability and security of the service.

This is an initial outline, and all ideas and responsibilities are open to discussion.

## Main Project Goals

- Create a basic web application for testing.
- Set up load balancing between multiple servers.
- Implement automatic failover if a server goes offline.
- Automate backups and demonstrate data recovery.
- Implement basic DDoS protection, such as rate limiting.
- Test the system under different conditions.

## Proposed Division of Work

Since we have five group members, we could divide the work into five sections.

**Member 1 — Web Application**
- Create a simple website for testing.
- Set up the application to run on multiple servers.

**Member 2 — Load Balancing & Failover**
- Configure load balancing between servers.
- Implement automatic failover when a server goes offline.

**Member 3 — Automated Backups**
- Create a system for scheduled backups.
- Demonstrate restoring data from a backup.

**Member 4 — DDoS Protection**
- Research DDoS attacks and prevention methods.
- Implement rate limiting and simulate high traffic in a controlled environment.

**Member 5 — Monitoring & Testing**
- Monitor server performance and availability.
- Test different failure scenarios and record results.

## Final Presentation

For our presentation, we could demonstrate:

1. The website operating normally.
2. Automatic failover when a server goes offline.
3. How the system handles high traffic.
4. How DDoS protection helps manage excessive requests.
5. Restoring data using an automated backup.

Each member could present their assigned section and explain how it contributes to the overall project.
